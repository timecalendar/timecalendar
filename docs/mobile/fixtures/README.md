# Calendar fixtures

Public iCal feeds for manual testing of the mobile calendar import flow. Hosted in the
`timecalendar-dev-public` Space under `ical/`, served through `cdn-dev.timecalendar.app`.
Scan a QR code from the device to import the feed.
